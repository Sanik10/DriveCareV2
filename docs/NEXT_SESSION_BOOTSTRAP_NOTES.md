Аудит (универсально, без кода)
Проведи аудит модуля и периферии. На этом шаге код/патчи не присылай.
- Покрой: ФЗ РФ (152, 242, 402, 54, 161, PCI при необходимости), безопасность (auth/RBAC/XSS/SQLi/CSRF/headers/cookies/PII/аудит/ретеншн), качество кода (архитектура, типизация, DTO/валидация, транзакции, перфоманс).
- Дай список конкретных изменений, приоритеты и краткую мотивацию. После подтверждения — попрошу патч.

Правки — Backend (unified diff)
Сгенерируй изменения ОДНИМ или несколькими unified diff патч-блоками от корня репозитория:
- Каждый патч внутри отдельного блока ```diff (или ```patch). Вне блоков — можно краткие комментарии без кода.
- Пути строго от корня монорепо: a/apps/backend/... и b/apps/backend/...
- Контекст в хунках ≥ 3 строки. Без “...”.
- Новый файл: --- /dev/null и +++ b/<path> (желательно new file mode 100644).
- Удаление файла: --- a/<path> и +++ /dev/null (желательно deleted file mode).
- Переименования — предпочтительно как удаление + новый файл (или валидный rename diff).
- Если патч большой — разбей на несколько diff-блоков (скрипт применит все по порядку). Никаких других код-блоков.

Правки — Frontend (unified diff)
То же самое, только пути:
- Пути: a/apps/frontend/... и b/apps/frontend/...
- Остальные требования идентичны (контекст ≥ 3 строки, новые/удалённые файлы через /dev/null, без “...”, можно несколько diff-блоков).

Fallback, если патч невозможен — полные файлы (path-blocks)
Если не можешь выдать корректный unified diff, пришли полные файлы блоками:

<!-- path: apps/backend/src/..., action: replace -->
```ts
<полный контент файла>
```

Удаление файла:
<!-- path: apps/backend/src/.../old.ts, action: delete -->
```txt
```

Перенос/переименование:
<!-- path: apps/backend/src/.../new.ts, action: move, from: apps/backend/src/.../old.ts -->
```ts
<опционально новый контент после move>
```

Памятка
- Сначала аудит без кода → потом патчами.
- Для бэка — apps/backend/...; для фронта — apps/frontend/...
- Можно несколько diff-блоков в одном сообщении.
- Удаление строк/кусков — обычный unified diff (строки с - удаляются, с + добавляются).
