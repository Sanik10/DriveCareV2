# 🎨 **ПЛАН МОДЕРНИЗАЦИИ UI - ЭТАП 3**

## **🗺️ ОБЩАЯ СТРАТЕГИЯ**

### **Принцип "Одна фишка на модуль":**
Каждый модуль получает уникальную визуальную фишку, которая делает его запоминающимся и функциональным.

### **Единые стандарты:**
- Кнопки: `rounded-2xl` (основные), `rounded-xl` (вторичные)
- Карточки: `rounded-3xl` с `glass` эффектами
- Анимации: адаптивные (отключаются при `prefers-reduced-motion`)
- Цветовая схема: следуем NeoCarbon Refined v0.3
- Отступы: консистентные 4/6/8 для spacing

---

## **📋 МОДУЛИ ДЛЯ ОБНОВЛЕНИЯ**

### **1. 🛠️ ORDERS (Заказы)** 
**Фишка:** Интерактивная Канбан-доска с плавным DnD

**Описание:**
- Колонки статусов с цветовым кодированием (new/in_progress/awaiting_parts/completed/canceled)
- Drag & Drop карточек между колонками меняет статус заказа
- Каждая карточка заказа показывает: номер, клиент, автомобиль, сумма, исполнитель
- Hover эффекты с lift и glow
- Детальная страница заказа с вкладками: Services/Parts/Finance/History

**Кнопки и навигация:**
- Главная: "Создать заказ" (primary, `rounded-2xl`)
- В карточках: "Открыть" (outline, `rounded-xl`)
- Смена статуса: цветные badges с hover эффектами
- Фильтры: по статусу, исполнителю, клиенту (компактные toggles)

**VFX:** Легкие particles при DnD операциях

---

### **2. 👥 CUSTOMERS (Клиенты)**
**Фишка:** Timeline истории клиента с интерактивными событиями

**Описание:**
- Список клиентов с аватарами и quick stats
- На странице клиента: вертикальный timeline всех взаимодействий
- События: заказы, звонки, оплаты, жалобы с иконками и датами
- Hover по событию показывает детали в tooltip
- Группировка по месяцам с возможностью сворачивания

**Кнопки и навигация:**
- Главная: "Добавить клиента" (primary, `rounded-2xl`)
- В строках: "Профиль" (ghost, `rounded-xl`)
- На профиле: "Редактировать", "Новый заказ", "Позвонить"
- Timeline: expand/collapse buttons для периодов

**VFX:** Пульсирующие точки для активных событий

---

### **3. 🚗 VEHICLES (Автомобили)**
**Фишка:** Карточки автомобилей с техническими характеристиками

**Описание:**
- Сетка карточек с фото автомобилей (placeholder если нет фото)
- Каждая карточка: марка, модель, год, VIN, владелец, статус ТО
- Цветовые индикаторы: зеленый (ТО актуально), желтый (скоро), красный (просрочено)
- Детальная страница: полная техническая информация + история ремонтов
- Фильтры по маркам, годам, статусу ТО

**Кнопки и навигация:**
- Главная: "Добавить ТС" (primary, `rounded-2xl`)
- Карточки: "Подробнее" (outline, `rounded-xl`)
- Детали: "Редактировать", "Новый заказ", "История ТО"
- Quick actions: "Записать на ТО" (accent color)

**VFX:** Subtle glow для карточек с просроченным ТО

---

### **4. 📅 APPOINTMENTS (Записи)**
**Фишка:** Календарная сетка с цветовым кодированием времени

**Описание:**
- Месячный/недельный/дневной вид календаря
- Слоты времени с цветовым кодированием: свободно/занято/перерыв
- Drag & Drop для перемещения записей
- Popup для быстрого создания записи при клике на слот
- Боковая панель с фильтрами по мастерам и типам работ

**Кнопки и навигация:**
- Навигация: "Сегодня", стрелки месяцев (outline, `rounded-xl`)
- Главная: "Новая запись" (primary, `rounded-2xl`)
- В событиях: quick actions для завершения/переноса
- Переключатели вида: день/неделя/месяц (toggle group)

**VFX:** Анимированные переходы между видами календаря

---

### **5. 📄 INVOICES (Счета)**
**Фишка:** Статусы оплаты с прогресс-барами и автообновлением

**Описание:**
- Таблица счетов с колонками: номер, клиент, сумма, статус, дата
- Цветовые статусы: draft/sent/paid/overdue/cancelled
- Прогресс-бары для частично оплаченных счетов
- Auto-refresh каждые 30 сек для статусов оплаты
- Детальная страница: PDF preview + кнопки действий

**Кнопки и навигации:**
- Главная: "Создать счет" (primary, `rounded-2xl`)
- В строках: "Открыть", "Отправить", "Скачать PDF"
- Статусы: интерактивные badges с tooltip
- Bulk actions: "Отправить выбранные", "Экспорт"

**VFX:** Пульсирующие индикаторы для overdue счетов

---

### **6. 💳 PAYMENT METHODS (Способы оплаты)**
**Фишка:** Интерактивные переключатели методов оплаты

**Описание:**
- Карточки различных способов оплаты: наличные, карта, перевод, криптовалюта
- Toggle switches для включения/отключения методов
- Настройки для каждого метода (комиссии, лимиты)
- Real-time preview изменений
- Тестовые транзакции для проверки интеграций

**Кнопки и навигация:**
- Toggle switches для активации методов
- "Настроить" для каждого метода (outline, `rounded-xl`)
- "Сохранить изменения" (primary, `rounded-2xl`)
- "Тест платежа" (accent color)

**VFX:** Smooth toggle анимации с micro-interactions

## **🏗️ УНИВЕРСАЛЬНЫЕ КОМПОНЕНТЫ**

### **AppLayout Component:**
```tsx
<AppLayout>
  <AppSidebar /> {/* Единая навигация для всех модулей */}
  <AppHeader />   {/* Breadcrumbs + search + user menu */}
  <AppMain>       {/* Контент с консистентными отступами */}
    {children}
  </AppMain>
</AppLayout>
```

### **Sidebar Navigation Items:**
- Dashboard (home icon)
- Orders (wrench, + канбан фишка)
- Customers (users, + timeline фишка) 
- Vehicles (car, + ТО индикаторы)
- Appointments (calendar, + цветовые слоты)
- Invoices (file-text, + статус индикаторы)
- Payment Methods (credit-card, + toggle состояния)
- Security (shield, + 2FA статус)

## **📱 АДАПТИВНОСТЬ**

### **Breakpoints:**
- Mobile: < 768px (стекированные карточки)
- Tablet: 768px - 1024px (сетка 2 колонки)
- Desktop: > 1024px (полная сетка)

### **Mobile-специфичные фишки:**
- Orders: компактные карточки канбана
- Customers: timeline в accordion формате
- Vehicles: список вместо сетки
- Appointments: дневной вид по умолчанию
- Invoices: swipe actions для quick actions

## **⚡ ПРОИЗВОДИТЕЛЬНОСТЬ**

### **Оптимизации:**
- Lazy loading для тяжелых компонентов
- Virtual scrolling для больших списков
- Debounced search и фильтры
- Optimistic updates для DnD операций
- Preloading для часто используемых маршрутов

### **VFX Management:**
- Auto-disable на слабых устройствах
- Respect `prefers-reduced-motion`
- localStorage setting для ручного управления
